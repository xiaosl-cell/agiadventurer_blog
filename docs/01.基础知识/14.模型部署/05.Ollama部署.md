Ollama 是一个简单易用的本地大模型运行工具，支持一键部署各种开源模型。

## 3.1 安装

### macOS / Linux

```bash
curl -fsSL https://ollama.com/install.sh | sh
```

### Windows

从 [ollama.com](https://ollama.com) 下载安装包。

## 3.2 基本使用

### 运行模型

```bash
# 运行 Qwen2.5
ollama run qwen2.5:7b

# 运行 Llama3
ollama run llama3:8b

# 运行 DeepSeek
ollama run deepseek-r1:7b
```

### 常用命令

| 命令 | 说明 |
| :--- | :--- |
| `ollama list` | 列出已下载的模型 |
| `ollama pull <model>` | 下载模型 |
| `ollama rm <model>` | 删除模型 |
| `ollama show <model>` | 查看模型信息 |

## 3.3 API 服务

Ollama 默认在 `http://localhost:11434` 提供 API 服务。

### 生成接口

```bash
curl http://localhost:11434/api/generate -d '{
  "model": "qwen2.5:7b",
  "prompt": "你好",
  "stream": false
}'
```

### 对话接口

```bash
curl http://localhost:11434/api/chat -d '{
  "model": "qwen2.5:7b",
  "messages": [
    {"role": "user", "content": "你好"}
  ]
}'
```

### Python 调用

```python
import ollama

response = ollama.chat(
    model='qwen2.5:7b',
    messages=[
        {'role': 'user', 'content': '你好'}
    ]
)
print(response['message']['content'])
```

## 3.4 自定义模型

### 导入 GGUF 模型

创建 `Modelfile`：

```
FROM ./my-model.gguf

PARAMETER temperature 0.7
PARAMETER top_p 0.9

SYSTEM "你是一个有帮助的助手。"
```

创建模型：

```bash
ollama create my-model -f Modelfile
```

### 导入 Safetensors 模型

```
FROM ./model-directory

TEMPLATE """{{ .System }}

{{ .Prompt }}"""
```

## 3.5 配置选项

### 环境变量

| 变量 | 说明 | 默认值 |
| :--- | :--- | :--- |
| `OLLAMA_HOST` | 监听地址 | `127.0.0.1:11434` |
| `OLLAMA_MODELS` | 模型存储路径 | `~/.ollama/models` |
| `OLLAMA_NUM_PARALLEL` | 并行请求数 | `1` |

### 允许远程访问

```bash
OLLAMA_HOST=0.0.0.0:11434 ollama serve
```
