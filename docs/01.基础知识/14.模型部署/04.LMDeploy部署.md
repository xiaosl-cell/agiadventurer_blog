LMDeploy 是由上海人工智能实验室（书生·浦语团队）开发的高效推理和部署工具包，针对国产模型有良好的支持。

## 7.1 核心特性

| 特性 | 说明 |
| :--- | :--- |
| **TurboMind** | 高性能推理引擎，基于 FasterTransformer |
| **持续批处理** | 动态批处理，提高吞吐量 |
| **量化支持** | 支持 W4A16、W8A8、KV Cache 量化 |
| **多模态** | 支持 InternVL、LLaVA 等视觉模型 |
| **国产模型** | 对 InternLM、Qwen 等有深度优化 |

## 7.2 安装

```bash
pip install lmdeploy
```

## 7.3 快速推理

### 命令行对话

```bash
lmdeploy chat Qwen/Qwen2.5-7B-Instruct
```

### Python 推理

```python
from lmdeploy import pipeline

pipe = pipeline("Qwen/Qwen2.5-7B-Instruct")
response = pipe(["你好，请介绍一下自己"])
print(response[0].text)
```

### 多轮对话

```python
from lmdeploy import pipeline, GenerationConfig, ChatTemplateConfig

pipe = pipeline("Qwen/Qwen2.5-7B-Instruct")

# 多轮对话
messages = [
    {"role": "user", "content": "你好"}
]
response = pipe(messages)
print(response.text)

messages.append({"role": "assistant", "content": response.text})
messages.append({"role": "user", "content": "你能做什么？"})
response = pipe(messages)
print(response.text)
```

## 7.4 API 服务

### 启动服务

```bash
lmdeploy serve api_server Qwen/Qwen2.5-7B-Instruct \
    --server-port 23333 \
    --tp 1
```

### 常用参数

| 参数 | 说明 | 示例 |
| :--- | :--- | :--- |
| `--server-port` | 服务端口 | `23333` |
| `--tp` | 张量并行数 | `2` |
| `--cache-max-entry-count` | KV Cache 比例 | `0.8` |
| `--model-format` | 模型格式 | `hf`, `awq` |
| `--quant-policy` | 量化策略 | `4`, `8` |

### API 调用

```python
from openai import OpenAI

client = OpenAI(
    base_url="http://localhost:23333/v1",
    api_key="not-needed"
)

response = client.chat.completions.create(
    model="Qwen/Qwen2.5-7B-Instruct",
    messages=[
        {"role": "user", "content": "你好"}
    ]
)
print(response.choices[0].message.content)
```

## 7.5 模型量化

### W4A16 量化（权重 4-bit）

```bash
lmdeploy lite auto_awq Qwen/Qwen2.5-7B-Instruct \
    --work-dir Qwen2.5-7B-Instruct-4bit
```

### 使用量化模型

```bash
lmdeploy chat Qwen2.5-7B-Instruct-4bit --model-format awq
```

### KV Cache 量化

```bash
# INT8 KV Cache
lmdeploy serve api_server Qwen/Qwen2.5-7B-Instruct \
    --quant-policy 8

# INT4 KV Cache
lmdeploy serve api_server Qwen/Qwen2.5-7B-Instruct \
    --quant-policy 4
```

## 7.6 多模态部署

### 视觉语言模型

```python
from lmdeploy import pipeline
from lmdeploy.vl import load_image

pipe = pipeline("OpenGVLab/InternVL2-8B")

image = load_image("https://example.com/image.jpg")
response = pipe(("描述这张图片", image))
print(response.text)
```

### 启动多模态服务

```bash
lmdeploy serve api_server OpenGVLab/InternVL2-8B
```

## 7.7 性能优化

### 推理引擎选择

```python
from lmdeploy import pipeline, TurbomindEngineConfig

# TurboMind 引擎（推荐，性能更好）
backend_config = TurbomindEngineConfig(tp=1)
pipe = pipeline("Qwen/Qwen2.5-7B-Instruct", backend_config=backend_config)

# PyTorch 引擎（兼容性更好）
from lmdeploy import PytorchEngineConfig
backend_config = PytorchEngineConfig(tp=1)
pipe = pipeline("Qwen/Qwen2.5-7B-Instruct", backend_config=backend_config)
```

### 生成参数配置

```python
from lmdeploy import GenerationConfig

gen_config = GenerationConfig(
    top_p=0.8,
    top_k=40,
    temperature=0.7,
    max_new_tokens=512
)

response = pipe("你好", gen_config=gen_config)
```
