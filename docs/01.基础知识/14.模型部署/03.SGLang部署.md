SGLang（Structured Generation Language）是一个高性能的 LLM 推理框架，专注于结构化生成和复杂推理场景，性能在多项基准测试中超越 vLLM。

## 6.1 核心特性

| 特性 | 说明 |
| :--- | :--- |
| **RadixAttention** | 自动 KV Cache 复用，加速前缀共享场景 |
| **结构化生成** | 原生支持 JSON Schema、正则约束 |
| **推测解码** | 支持 Speculative Decoding 加速 |
| **多模态** | 支持视觉语言模型（VLM） |
| **高吞吐** | 在多项基准测试中性能领先 |

## 6.2 安装

```bash
pip install sglang[all]

# 或者从源码安装
pip install "sglang[all] @ git+https://github.com/sgl-project/sglang.git"
```

## 6.3 启动服务

### 命令行启动

```bash
python -m sglang.launch_server \
    --model-path Qwen/Qwen2.5-7B-Instruct \
    --host 0.0.0.0 \
    --port 30000
```

### 常用参数

| 参数 | 说明 | 示例 |
| :--- | :--- | :--- |
| `--model-path` | 模型路径 | `Qwen/Qwen2.5-7B-Instruct` |
| `--tp` | 张量并行数 | `2` |
| `--mem-fraction-static` | 静态显存比例 | `0.9` |
| `--context-length` | 上下文长度 | `8192` |
| `--quantization` | 量化方式 | `awq`, `fp8` |
| `--enable-torch-compile` | 启用编译优化 | - |

## 6.4 API 调用

SGLang 提供 OpenAI 兼容的 API：

```python
from openai import OpenAI

client = OpenAI(
    base_url="http://localhost:30000/v1",
    api_key="not-needed"
)

response = client.chat.completions.create(
    model="Qwen/Qwen2.5-7B-Instruct",
    messages=[
        {"role": "user", "content": "你好"}
    ]
)
print(response.choices[0].message.content)
```

## 6.5 结构化生成

SGLang 的核心优势是结构化生成，可以约束输出格式。

### JSON Schema 约束

```python
import sglang as sgl

@sgl.function
def extract_info(s, text):
    s += "从以下文本中提取信息：\n" + text + "\n"
    s += "请以JSON格式输出：\n"
    s += sgl.gen("result", max_tokens=256, 
                  regex=r'\{"name": "[^"]+", "age": \d+\}')

# 运行
state = extract_info.run(text="张三今年25岁")
print(state["result"])
```

### 选择约束

```python
@sgl.function
def classify(s, text):
    s += f"对以下文本进行情感分类：{text}\n"
    s += "情感：" + sgl.gen("sentiment", choices=["正面", "负面", "中性"])
```

## 6.6 前缀缓存（RadixAttention）

SGLang 自动复用相同前缀的 KV Cache，适合：

- 多轮对话（共享历史）
- Few-shot 学习（共享示例）
- 批量处理（共享系统提示）

```python
# 多个请求共享相同的系统提示，自动复用缓存
system_prompt = "你是一个专业的翻译助手。"

requests = [
    system_prompt + "翻译：Hello",
    system_prompt + "翻译：World",
    system_prompt + "翻译：Good morning",
]
```

## 6.7 多 GPU 部署

### 张量并行

```bash
python -m sglang.launch_server \
    --model-path Qwen/Qwen2.5-72B-Instruct \
    --tp 4
```

### 数据并行

```bash
python -m sglang.launch_server \
    --model-path Qwen/Qwen2.5-7B-Instruct \
    --dp 2
```

## 6.8 性能对比

在 ShareGPT 数据集上的吞吐量对比（越高越好）：

| 框架 | 吞吐量 (req/s) |
| :--- | :--- |
| SGLang | ~1.2x vLLM |
| vLLM | 基准 |
| TGI | ~0.8x vLLM |

> 实际性能取决于具体场景，建议自行测试。

## 6.9 Docker 部署

```bash
docker run --gpus all \
    -p 30000:30000 \
    -v ~/.cache/huggingface:/root/.cache/huggingface \
    lmsysorg/sglang:latest \
    python -m sglang.launch_server \
    --model-path Qwen/Qwen2.5-7B-Instruct \
    --host 0.0.0.0
```

## 6.10 选择建议

| 场景 | 推荐 |
| :--- | :--- |
| 需要结构化输出（JSON等） | ✅ SGLang |
| 多轮对话、前缀共享 | ✅ SGLang |
| 追求极致吞吐量 | ✅ SGLang |
| 生态成熟度要求高 | vLLM |
| 简单部署 | Ollama |
