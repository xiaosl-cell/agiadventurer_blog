llama.cpp 是一个纯 C/C++ 实现的 LLM 推理框架，支持 CPU 推理和多种量化格式，适合资源受限的环境。

## 4.1 特点

- **纯 CPU 推理**：无需 GPU 即可运行
- **多种量化**：支持 2-8 bit 量化，大幅减少内存占用
- **跨平台**：支持 Windows、Linux、macOS、Android、iOS
- **GGUF 格式**：统一的模型格式，易于分发

## 4.2 安装

### 编译安装

```bash
git clone https://github.com/ggerganov/llama.cpp
cd llama.cpp
make -j
```

### GPU 加速编译

```bash
# CUDA
make GGML_CUDA=1 -j

# Metal (macOS)
make GGML_METAL=1 -j
```

## 4.3 模型转换

### 转换为 GGUF 格式

```bash
python convert_hf_to_gguf.py \
    /path/to/model \
    --outfile model.gguf \
    --outtype f16
```

### 量化

```bash
# Q4_K_M 量化（推荐）
./llama-quantize model.gguf model-q4_k_m.gguf Q4_K_M

# Q8_0 量化（质量更高）
./llama-quantize model.gguf model-q8_0.gguf Q8_0
```

### 量化级别对比

| 量化类型 | 大小 | 质量 | 速度 |
| :--- | :--- | :--- | :--- |
| Q2_K | 最小 | 较差 | 最快 |
| Q4_K_M | 小 | 良好 | 快 |
| Q5_K_M | 中等 | 很好 | 中等 |
| Q8_0 | 较大 | 优秀 | 较慢 |
| F16 | 最大 | 最佳 | 最慢 |

## 4.4 命令行推理

```bash
./llama-cli \
    -m model-q4_k_m.gguf \
    -p "你好，请介绍一下自己" \
    -n 256 \
    --temp 0.7
```

### 常用参数

| 参数 | 说明 |
| :--- | :--- |
| `-m` | 模型文件路径 |
| `-p` | 提示词 |
| `-n` | 生成的最大 token 数 |
| `-c` | 上下文长度 |
| `--temp` | 温度参数 |
| `-ngl` | GPU 层数（需要 GPU 编译） |

## 4.5 API 服务

### 启动服务

```bash
./llama-server \
    -m model-q4_k_m.gguf \
    --host 0.0.0.0 \
    --port 8080
```

### API 调用

```bash
curl http://localhost:8080/completion \
    -H "Content-Type: application/json" \
    -d '{
        "prompt": "你好",
        "n_predict": 128
    }'
```

### OpenAI 兼容模式

```bash
./llama-server \
    -m model-q4_k_m.gguf \
    --api-key your-api-key
```

```python
from openai import OpenAI

client = OpenAI(
    base_url="http://localhost:8080/v1",
    api_key="your-api-key"
)

response = client.chat.completions.create(
    model="gpt-3.5-turbo",  # 模型名称会被忽略
    messages=[{"role": "user", "content": "你好"}]
)
```

## 4.6 性能优化

### GPU 卸载

```bash
# 将 35 层卸载到 GPU
./llama-cli -m model.gguf -ngl 35 -p "Hello"
```

### 批处理

```bash
./llama-server -m model.gguf --batch-size 512
```
