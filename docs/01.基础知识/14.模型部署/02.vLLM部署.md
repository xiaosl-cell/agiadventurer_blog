vLLM 是目前最流行的高性能 LLM 推理引擎，通过 PagedAttention 技术实现高吞吐量推理。

## 2.1 核心特性

- **PagedAttention**：高效的 KV Cache 管理，显存利用率提升 2-4 倍
- **连续批处理**：动态合并请求，提高吞吐量
- **张量并行**：支持多 GPU 分布式推理
- **OpenAI 兼容 API**：无缝替换 OpenAI 接口

## 2.2 安装

```bash
pip install vllm
```

## 2.3 快速启动

### 命令行启动

```bash
vllm serve Qwen/Qwen2.5-7B-Instruct \
    --host 0.0.0.0 \
    --port 8000 \
    --tensor-parallel-size 1
```

### 常用参数

| 参数 | 说明 | 示例 |
| :--- | :--- | :--- |
| `--model` | 模型路径或名称 | `Qwen/Qwen2.5-7B-Instruct` |
| `--tensor-parallel-size` | GPU 并行数 | `2` |
| `--gpu-memory-utilization` | GPU 显存利用率 | `0.9` |
| `--max-model-len` | 最大上下文长度 | `4096` |
| `--quantization` | 量化方式 | `awq`, `gptq` |

## 2.4 API 调用

vLLM 提供 OpenAI 兼容的 API：

```python
from openai import OpenAI

client = OpenAI(
    base_url="http://localhost:8000/v1",
    api_key="not-needed"
)

response = client.chat.completions.create(
    model="Qwen/Qwen2.5-7B-Instruct",
    messages=[
        {"role": "user", "content": "你好"}
    ]
)
print(response.choices[0].message.content)
```

## 2.5 性能优化

### 量化部署

```bash
# AWQ 量化模型
vllm serve Qwen/Qwen2.5-7B-Instruct-AWQ \
    --quantization awq

# GPTQ 量化模型
vllm serve Qwen/Qwen2.5-7B-Instruct-GPTQ-Int4 \
    --quantization gptq
```

### 多 GPU 部署

```bash
vllm serve Qwen/Qwen2.5-72B-Instruct \
    --tensor-parallel-size 4
```

## 2.6 Docker 部署

```bash
docker run --gpus all \
    -v ~/.cache/huggingface:/root/.cache/huggingface \
    -p 8000:8000 \
    vllm/vllm-openai:latest \
    --model Qwen/Qwen2.5-7B-Instruct
```
