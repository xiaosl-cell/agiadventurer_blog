## 3.1 前期准备

1. 拉取官方源码：[https://github.com/google/A2A](https://github.com/google/A2A)
2. Python环境管理: uv
3. 获取GOOGLE_API_KEY
   - 启用Google API: [https://console.cloud.google.com/](https://console.cloud.google.com/)
   - 启用Gemini API
4. 在ui、以及要跑的Agent目录配置`.env`

## 3.2 UI界面启动

```bash
# 先进入代码工程的根目录下
cd demo/ui
echo "GOOGLE_API_KEY=your_api_key_here" > .env
uv run main.py
```

访问 [http://localhost:12000](http://localhost:12000)

```bash

uv run . --port 8080
```
